STEPS FOR SAVING THE D's
1. create the characters using the .py file
2. open file explorer
3. COPY the "D's" file from the repository destination to your desired location
--> this can be your computers SSD, a USB drive, or anything else
4. open the file you just copied into and change the file name from "D's"

YOU HAVE TO SWITCH BACK AND FORTH BETWEEN THE .PY AND THE .TXT FILE FOR THE CHARACTERS TO APPEAR
